# Kanji Combat

Standalone N5 Japanese workout app. Public repository excludes user-uploaded image and WAV. Copy to web/feitan.png and web/battle.wav before build, or import from Settings once installed. 674 words, 84 kanji, 664 entries with examples. Open web/index.html in a browser; Android uses offline WebView. JDK 17, SDK 35, Gradle 8.9: run `gradle :app:assembleDebug` inside kanji-combat. APK: app/build/outputs/apk/debug/app-debug.apk. Progress is local, not synced. See NOTICE.md for attribution.
