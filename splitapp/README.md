# AM/PM Split — standalone Android app

Landscape-only, offline workout plan, separate from IN MOTION.
Tap any day/session to open its exercise protocol. Biceps has full details including two warm-up and two working alternating hammer sets, ordinary dumbbell curls, reverse EZ/barbell curls, and optional preacher machine curls. HOME/GYM mode adjusts the exercise count. Per-set checkmarks are stored locally.

Build: cd splitapp && gradle assembleDebug
APK: splitapp/app/build/outputs/apk/debug/app-debug.apk
